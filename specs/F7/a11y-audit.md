# F7-AC2 · Аудит доступності панелей (сб, до 14:00)

Як перевіряли: `npm run build && vite preview`, Playwright (headless Chromium, без WebGL → 2D-план Б), 400 і 1440 px, стани «глобус» і «Gale + 1 ціль»; Tab ×30, доступні назви, розмір цілей, `img alt`, полотна. Код — гілка `feat/F7` (= `main` + F7). Інші панелі зараз заглушки F0, тож це список «що не забути», а не баги.

## Що вже гаразд (усі панелі)
- Горизонтального скролу немає (400 і 1440 px).
- Фокус видно: `outline: solid 3px` на кожному фокусованому елементі (глобально з `src/ui/tokens.css`).
- Усі видимі кнопки й поля ≥40×40 px, усі мають доступну назву.
- Порядок Tab: HUD → камера → Location → цілі — збігається з візуальним на 400 px.
