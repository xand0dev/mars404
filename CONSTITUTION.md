# Конституція MARS::404

1. **Продукт.** Планшет / HUD для пішого виходу на гору Шарпа (Gale): наука, безпечний шлях, момент розвороту. Демонстраційна модель, не сертифікована навігація. Найкращий статус — «within model», ніколи не «safe».
2. **Джерело правди** — `docs/SPEC.md`. Spec фічі (`specs/F<N>/spec.md`) уточнює, але не суперечить їй. За розбіжності перемагає `docs/SPEC.md`.
3. **Стек.** Vite + React + TypeScript (strict) + three / R3F / drei + Zustand. Статичний сайт, `base: './'`, без backend і ключів. Дані готує офлайн `pipeline/` (Python + GDAL у Docker).
4. **Обмін.** Фічі спілкуються лише через `useMission`; типи — лише з `src/contracts`. Чужі `src/features/*` не імпортуємо. Змінити contracts, store, app, mocks чи конфіги — окремий PR з міткою `contract`; поки його немає, працюємо на mocks.
5. **Папки.** Кожен пише лише у свої шляхи (SPEC §9, `.github/scripts/paths.mjs`) плюс `specs/F<N>/**` і свій розділ у `docs/AI_LOG.md` та `docs/SOURCES.md`. Тести лежать поруч із кодом у своїй папці.
6. **SDD.** Spec → тести з AC (red) → мінімальний код (green). Поведінка змінюється спершу в spec. AC не послаблюємо, щоб сховати збій.
7. **Чесність даних.** Жодних вигаданих NASA API, координат, фото чи чисел. Кожна константа має джерело або видиму позначку «assumption». Mock підписаний «MOCK». NoData — заблоковано, ніколи не 0 і не «безпечно». Невідомий бюджет ≠ безпечно.
8. **Доступність.** 400 px без горизонтального скролу, клавіатура, видимий фокус, ризик іконкою + текстом, reduced motion. Ціль ≥30 FPS на ноутбуці демо.
9. **Merge.** `npm run check` зелений, guard зелений, PR не draft → automerge squash. PR зі спільними файлами мерджить @xand0dev. Один відкритий PR на фічу.
10. **AI.** Код генерують агенти, люди пишуть spec і перевіряють AC у браузері. Кожна AI-сесія — рядок у `docs/AI_LOG.md`; використання AI розкриваємо в сабміті. Комітів, PR і коментарів з підписами агентів («Generated with…», «Co-Authored-By: <агент>») немає.
11. **З нуля.** Кодова база створюється на хакатоні в цій репі. Ліцензія Apache-2.0.
